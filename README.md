# Tabular Foundation Models for Novelty Detection (TABNOV)

A repository for exploring, reviewing, and benchmarking **Tabular Foundation Models (TABFMs)** applied to **novelty detection**.

---

## Project Structure

- **`docs/`**: Literature review, notes, and references.
  - **`literature_review.md`**: Main literature review document containing:
    - **Methods:** Pretrained anomaly detection foundation models and general-purpose TabFM adaptations.
    - **Datasets:** Overview of key anomaly detection benchmarks (e.g., ADBench, OddBench).
    - **Reported Benchmarks:** Comparative overview of baseline evaluations across papers.
